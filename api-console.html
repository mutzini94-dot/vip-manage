통합 API 관리자 사용법

이 도구는 API_SPEC.md의 엔드포인트를 브라우저에서 바로 테스트합니다. 두 가지 모드가 있습니다.

Mock 모드 (기본)

내장 목(mock) 서버가 메인 화면과 동일한 저장소(localStorage: toon_vip_v1)를 읽고 씁니다. 즉 여기서 데이터를 바꾸면 메인 화면에 그대로 반영됩니다.

실제 데이터 주입 → 화면 테스트

  1. 좌측 🎁 후원 주입 또는 POST /webhooks/donation 실행 (누적·등급·자동화가 갱신됨)
  2. 🖥 메인 화면 열기로 관리 화면을 열면, 방금 주입한 데이터로 랭킹·인사이트·로그가 렌더링됩니다
  3. ⬆ 가져오기로 실제 운영 데이터(JSON)를 통째로 대입할 수도 있습니다

HTTP 모드

상단에서 HTTP로 전환하고 Base URL·토큰을 입력하면 실제 서버로 fetch합니다(CORS 필요).

팁

경로의 :id는 저장소의 실제 ID로 자동 채워집니다. Query/Body는 JSON으로 입력하세요.
