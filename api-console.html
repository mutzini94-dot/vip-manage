VIP 도네이터 관리 — 개발 정책 문서

투네이션 크리에이터용 VIP 도네이터 관리(열혈시스템) 플랫폼의 아키텍처·데이터 모델·API 규약·개발 절차를 정의합니다. 신규 개발자는 이 문서를 먼저 숙지한 뒤 코드에 기여하세요.

버전 v1대상 vip-donator-manager.html · server/ · api-console.html최종 갱신 2026-08-18

1 개요

크리에이터가 자신에게 후원한 도네이터를 등급·칭호·자동화·인사이트로 관리하고, 큰손 VIP와의 관계를 이어가도록 돕는 관리 콘솔입니다. 핵심 가치는 이탈 방지(복귀 유도)와 후원 유도(승급 넛지·해피아워)입니다.

  • 프론트엔드: 단일 파일 SPA vip-donator-manager.html (바닐라 JS, 무빌드)
  • 백엔드: 의존성 0 Node 서버 server/src/* — 실제 운영 시 Express/Nest 교체 권장
  • 통합 API 관리자: api-console.html — 브라우저 내장 Mock 서버로 API를 즉시 테스트
  • 실시간: WebSocket 게이트웨이(ws://…/live) + 데모 live-client.html

2 시스템 아키텍처

┌────────────┐   REST/JSON   ┌──────────────┐        ┌──────────┐

└────────────┘               └──────────────┘        └──────────┘
      ▲                          ▲     ▲
      │ WebSocket(라이브)         │     │ Webhook(수신)
   실시간 이벤트 ─────────────────┘     └── 투네이션 후원/로그인 이벤트

데이터 어댑터 패턴 — 프론트는 ApiClient 추상화로 접근하며 어댑터만 교체합니다.

  • MockAdapter — 브라우저 localStorage 기반(오프라인/데모). 통합 API 관리자에 내장
  • HttpAdapter — 실제 REST 서버 호출
단일 저장소 원칙: 프론트엔드와 Mock 콘솔은 동일한 localStorage 키 toon_vip_v1를 공유합니다. 콘솔에서 데이터를 주입하면 관리 화면에 그대로 반영됩니다.

8 코드 컨벤션

  • 무빌드 단일 파일: 프론트는 외부 의존성/번들러 없이 vip-donator-manager.html 하나로 동작. 새 기능은 해당 탭의 renderX() 패턴을 따름
  • 디자인 토큰: 색상은 --ground/--surface/--accent 등 CSS 변수만 사용. 하드코딩 금지
  • 탭 구조: .tab[data-tab] + #page-* 섹션 + pages 맵 + 전환 시 renderX() 호출
  • 결정적 합성: 날짜별 후원은 seedRand()/dayDonations()로 결정적으로 생성(캘린더·인사이트·후원 내역 일관성 유지)
  • 저장: save()는 try/catch로 감싸 프라이빗 모드/쿼터 예외를 무시
  • 한국어 UI: 모든 라벨·토스트는 한국어. 커밋 메시지도 한국어 + Co-Authored-By 푸터

Mock 모드 (기본)

내장 목(mock) 서버가 메인 화면과 동일한 저장소(localStorage: toon_vip_v1)를 읽고 씁니다. 즉 여기서 데이터를 바꾸면 메인 화면에 그대로 반영됩니다.

실제 데이터 주입 → 화면 테스트
