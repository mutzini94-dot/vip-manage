# VIP 도네이터 관리 — 열혈시스템

크리에이터가 자신에게 후원한 **VIP 도네이터를 관리**하는 웹 도구입니다.
투네이션 다크 디자인 시스템 기반의 단일 HTML 프로토타입이며, 데이터는 브라우저 `localStorage`에 저장됩니다.

## 주요 기능

| 탭 | 설명 |
|----|------|
| **등급 관리** | 누적 후원 금액 기준으로 등급(VVIP·VIP·열혈 등)을 정의하고 도네이터를 자동 분류 |
| **도네이터 관리** | 후원 순위별·등급별 정렬, 닉네임/별칭 Like 검색, 인라인 별칭 편집 |
| **자동화 설정** | 상황(방송 시작·특정 도네이터·특정 금액) × 액션(카카오 알림톡·리모컨 알림·위젯 효과·TTS)을 STEP 1→2 마법사로 구성, 실시간 미리보기 |
| **도네이터 프로필** | 리모컨 연동 프로필 — 자주하는 후원, 획득한 칭호, 최근 후원 이력 |

## 실행

정적 파일이라 별도 빌드가 필요 없습니다.

```bash
# 로컬에서 바로 열기
start index.html
```

## 배포 (Vercel)

정적 사이트로 자동 배포됩니다. 루트 URL(`/`)에서 `index.html`이 서빙됩니다.
